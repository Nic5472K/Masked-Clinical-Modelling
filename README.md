### What’s New

* **New framework:**
  Masked Clinical Modelling (MCM) integrates *attention-guided masking and reconstruction* to predict missing or synthetic clinical features.

* **Enhanced focus:**
  Beyond raw data synthesis, MCM aligns generated data with **hazard ratios, discrimination (C-index),** and **calibration slopes** — ensuring synthetic data retains *clinical interpretability*.

* **Educational integration:**
  Hands-on walkthroughs, implementation notebooks, and reproducible examples for key survival datasets (WHAS500, GBSG2, ACTG320, FLChain).

* **Open-science alignment:**
  Fully documented code, visual abstracts, and continuous updates in partnership with the
  [Centre for Big Data Research in Health (CBDRH), UNSW Sydney](https://cbdrh.med.unsw.edu.au/).

# Masked-Clinical-Modelling
Masked Clinical Modelling (MCM) is a framework for synthetic and augmented survival data generation. Inspired by masked language modeling, MCM preserves hazard ratios to ensure clinical utility, improves discrimination and calibration in Cox models, and supports secure, utility-focused data sharing.
